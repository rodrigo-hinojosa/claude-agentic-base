Una forma distinta para cada tipo de relación.

El sistema documental usa diagramas estándar, conectores consistentes y lienzos amplios. La muestra es neutral: los nombres deben reemplazarse por conceptos del dominio documentado.

Reglas compartidas

  • Una pregunta principal por diagrama.
  • Etiquetas breves y legibles al 100 %.
  • Línea continua para acción principal; punteada para retorno o evento.
  • Scroll horizontal antes que texto diminuto.
  • Título, descripción y leyenda accesibles.
