03 · Composición · bloques editoriales

Patrones para convertir evidencia en una revisión técnica.

Las páginas combinan solo los bloques necesarios: contexto, comparación, decisión, contrato, responsabilidad y criterios de cierre.

HeroCardsDecision ledgerTablesContracts

Criterio de composición

  • Una pregunta principal por sección.
  • Prosa para contexto; tabla para exactitud.
  • Diagrama para relaciones, no decoración.
  • Contrato oscuro solo para información literal.
  • Dudas abiertas con impacto explícito.
Selección de bloque

El contenido determina la forma.

Evita repetir la misma afirmación en prosa, tarjeta y diagrama. Elige la representación que hace visible la relación importante.

Conceptos paralelos

Cards

Úsalas para tres o cuatro ideas de similar jerarquía que pueden leerse por separado.

No usarPara secuencias, dependencias o mapeos campo a campo.
Comparación exacta

Tabla

Úsala cuando varias filas comparten dimensiones, estados, owners o contratos.

No usarCuando el orden temporal o la dirección de una llamada importan.
Relación difícil

Diagrama

Úsalo para componentes, decisiones, secuencia, estados, datos o despliegue.

CondiciónEl lector debe obtener una conclusión que no era obvia en una lista.
Interacción visible

Wireframe

Úsalo para revisar información, acción, feedback, error y recuperación.

CondiciónDebe estar rotulado LOW-FI y, si aplica, mostrar su capa sistémica.
Decision ledger

Separar certeza, propuesta y duda.

La forma evita que una inferencia visual parezca una decisión ya tomada.

Confirmado
El evento se publica después del commit.

Comportamiento acordado; la documentación puede afirmarlo.

Propuesto
Usar outbox transaccional como baseline.

Alternativa técnica recomendada, sujeta a revisión de plataforma.

Abierto
¿Qué equipo opera el replay de eventos?

Impacta ownership, alertas y runbook; owner de decisión: por definir.

Contrato técnico

El contenido literal vive en un bloque dedicado.

La descripción explica intención y garantías; el área oscura conserva nombres y estructura exactos.
