Un lenguaje visual para explicar sistemas complejos.

El sistema documental combina una composición editorial, diagramas técnicos estándar y wireframes inequívocamente conceptuales en un sitio HTML enlazado y sin dependencias externas.

MonocromáticoOfflineResponsiveTécnicoNo es UI final

Firma del formato

  • Lienzo gris cálido y superficies de papel blanco.
  • Títulos grandes y metadata monospace compacta.
  • Bordes y patrones, no color, para distinguir estados.
  • Diagramas con simbología estándar y leyenda.
  • Wireframes low-fi conectados con su efecto sistémico.
Principios

Debe verse técnico, neutral y revisable.

La forma ordena la discusión sin apropiarse del lenguaje visual del producto que se está documentando.

Editorial

Una ruta de lectura, títulos con tesis y secciones que responden preguntas.

Sistémico

Componentes, decisiones, mensajes y persistencia aparecen en su nivel correcto.

Low-fi

Las pantallas explican estados y no simulan una interfaz aprobada.

Portable

HTML y CSS relativos, sin CDN, fuentes remotas ni runtime obligatorio.

Tokens de color

Ocho tonos, una jerarquía.

El negro marca acciones o énfasis; el punteado comunica propuesta o frontera. Ningún significado depende solo del color.
